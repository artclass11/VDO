# VDO Studio Offline — Desktop App

A minimal black-theme desktop app for Windows, macOS and Linux. It uses a local Ollama model at 127.0.0.1:11434 to expand one prompt into a practical film-edit brief, then generates an auditable editorial/color handoff package.

## Prepare once, work offline thereafter

1. Install Ollama on your computer.
2. Download a model once while connected, for example: ollama pull qwen3:8b
3. Install FFmpeg so ffprobe is on PATH.
4. Install dependencies from the repository root:
   
       python -m pip install "mcp>=2,<3" "OpenTimelineIO>=0.18,<1"

5. Start Ollama with ollama serve if it is not running.
6. Launch:

       python desktop/vdo_studio.py

The app only contacts Ollama on loopback (127.0.0.1); it does not call hosted inference APIs. After the model and dependencies are installed, editing plans and color files can be generated without internet access.

## Build a standalone app

Install PyInstaller:

    python -m pip install pyinstaller

From the repository root:

    pyinstaller --noconfirm --onefile --windowed --paths . --name VDO-Studio desktop/vdo_studio.py

The output is in the dist directory. A CI workflow builds platform-specific artifacts.

## Generated files

- media_manifest.json — local media inventory
- EDIT_PLAN.json — reviewable shot order and trims
- interchange/ — FCPXML and EDL, with OTIO when installed
- color/ — .cube, ASC CDL, and grade recipe
- LOCAL_LLM_EDIT_BRIEF.txt — refined brief generated by the local model
- editor-specific handoff guidance

This is a post-production planning/transfer tool, not a replacement for rendering and final manual review inside the target NLE. CapCut and VN use guided open-interchange handoffs because VDO intentionally does not depend on undocumented private project files.
